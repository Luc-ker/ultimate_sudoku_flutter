# Luc-ker's Sudoku App
## The (soon-to-be) ultimate Sudoku app, made using Flutter.

### Supported platforms (or ones that are planning to be supportable)
- Android
- iOS
- Windows
- Linux
- MacOS
- Web

### How to run the app
```
[fvm] flutter pub get
[fvm] dart run build_runner build
[fvm] flutter run
```
